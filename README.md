# 🛰️ Nex Tech (المساعد الزراعي الذكي) - AgriTech MVP

منصة وتطبيق ويب متكامل (Single Page Application) للمساعد الزراعي الذكي **"Nex Tech"** يدمج بيانات الأقمار الصناعية لوكالة ناسا (NASA Landsat 9 & Sentinel-2) مع نماذج الذكاء الاصطناعي لتشخيص أمراض النبات وسوق مستلزمات زراعية معتمد بالشراكة مع كبرى الشركات الزراعية مثل **شركة ميلانو**.

---

## 🎨 الهوية البصرية والتصميم (Dark Mode & Space Theme)

- **الاتجاه واللغة:** واجهة عربية كاملة 100% بنظام RTL (`dir="rtl"`) مع خط **Cairo** الحديث.
- **لون الخلفية الأساسي:** أسود كوني عميق (`#000000`).
- **ألوان البطاقات واللوحات:** رمادي داكن فاحم (`#0A0A0A` / `#121215`).
- **لون التمييز الفضائي (Accent):** Space Purple (`#B27BFF`) مع تأثيرات التوهج الضوئي (`shadow-[0_0_15px_#B27BFF]`).
- **ألوان النصوص:** أبيض ناصع (`#FFFFFF`) للعناوين، ورمادي ناعم (`#9CA3AF`) للفقرات.

---

## 🧭 بنية التطبيق والتنقل عبر الحالات (State-Based Navigation)

يتنقل التطبيق بسلاسة تامة وبدون إعادة تحميل للصفحة بين 3 واجهات رئيسية:

1. **الصفحة الرئيسية (Landing Page - View A):**
   - **شريط التنقل (Navbar):** شعار Nex Tech المداري على اليمين مع مؤشر رادار الأقمار، وزر «ادخل للتطبيق» المتوهج على اليسار.
   - **القسم الترويجي (Hero):** عنوان ضخم «أرضك تحت عيون الفضاء»، نبذة عن دمج بيانات ناسا والذكاء الاصطناعي، زران: «سجل مزرعتك مجاناً» و«اكتشف المميزات».
   - **لوحة بيانات الأقمار المباشرة:** تعرض دقة الرصد (10م)، مؤشر NDVI، وتوقيت الإنذارات.
   - **قسم الميزات الرئيسية (3 بطاقات):**
     1. جدولة الري والطقس الفضائي.
     2. التشخيص الذكي بالذكاء الاصطناعي.
     3. سوق المستلزمات والمبيدات المعتمدة.

2. **تهيئة بيانات المزرعة (Onboarding / Farm Setup - View B):**
   - بطاقة مركزية أنيقة لإدخال بيانات المزرعة:
     - **موقع المزرعة (قائمة منسدلة):** الفيوم، البحيرة، الدقهلية، الوادي الجديد، الشرقية، وغيرها.
     - **نوع المحصول (قائمة منسدلة وأزرار سريعة):** قمح، طماطم، بطاطس، ذرة، موالح، فراولة.
     - **مساحة الأرض بالفدان:** حقل رقمي مع خيارات سريعة (5، 10، 15، 50 فدان).
   - **زر «تحليل بيانات الأرض»:** يُشغل محاكاة تفاعلية حية للاتصال بأقمار NASA Landsat 9 & Sentinel-2 مع مؤشر تقدم ومراحل فحص دقيقة، ثم ينقل المزارع تلقائياً إلى لوحة التحكم.

3. **لوحة تحكم المزارع (Main App Dashboard - View C):**
   - شريط علوي يعرض ملخص الحقل وحالة الاتصال بالأقمار الصناعية.
   - شبكة CSS Grid مكونة من 3 ودجات رئيسية:
     - **ودجت 1 (NASA Climate & Soil):** درجات الحرارة اللحظية، قياس رطوبة التربة عبر القمر الصناعي، مؤشر NDVI، وتنبيه الصقيع البارز: *«تنبيه مناخي فضائي عاجل: موجة صقيع غداً، يرجى ري الأرض الليلة لتقليل أثر البرودة وحماية الجذور»* مع جدول ري أسبوعي ذكي.
     - **ودجت 2 (AI Crop Diagnosis):** منطقة تصوير ورفع الورقة المصابة مع إمكانية تجربة عينات جاهزة (بياض دقيقي، صدأ أصفر، لفحة، ورقة سليمة)، ومحاكاة ليزر المسح الضوئي، وإظهار نتيجة التشخيص ونسبة الثقة (96%) وبروتوكول العلاج.
     - **ودجت 3 (B2B/B2C Marketplace):** سوق المستلزمات مع فلترة المنتجات الموصى بها لنتيجة الفحص، مع منتجات «شركة ميلانو للمستلزمات الزراعية» (مثل ميلانو-فيت 500 وسوبر كبريت 80%)، وعرض الأسعار وزر «اطلب الآن» الذي يفتح نافذة تأكيد الطلب والشحن للمزرعة.

## 🛠️ التقنيات المستخدمة

- **Tailwind CSS** (Custom Space Dark Palette & Animations)
- **Lucide React** (Vector Icons)
- **Google Fonts** (Cairo Arabic Font)
